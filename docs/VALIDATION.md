# Public repository migration validation

Validated locally on **2026-11-20**, using **Blender 5.2.1 LTS** and the unchanged **Marionette Workflow Helper 1.4.0** source.

| Suite | Fresh checks | Result |
|---|---:|---|
| Synthetic smoke | 47 | Passed |
| Native extension installation | 10 | Passed |
| Total | 57 | Passed |

The suites ran in separate offline background processes with isolated preferences and extension directories. Python compilation of the test and runner files also passed. Installation used the public ZIP freshly generated by this repository's builder.

The smoke suite generated its own humanoid skeletons and keyed take. It checked naming/profile maps, independent capture copies, preset reference data, preview changes and cancellation cleanup, preservation of source keys and handles, independent baking, visibility restoration and registration cleanup. The install suite checked the built ZIP through Blender's native installer, metadata, portable preset presence, UI icons/reset operators and disable/re-enable.

No private production scenes, character models or official Marionette plugin code were used. A synthetic Tripo-profile skeleton is a naming/reference-pose test; it is not a visual-quality guarantee for arbitrary Tripo exports. This validation does not cover live Marionette networking or the official plugin's parser.

Historical private development recorded 172 checks involving its original fixtures and integration setup. They were not rerun for this public migration and are distinct from the 57 fresh checks above.

To reproduce from the repository root:

```sh
python scripts/run_tests.py --blender /path/to/blender
```

Logs and machine-readable summaries are written under ignored `build/test-runs/`. GitHub's lightweight CI checks Python syntax and packaging; it does not run the native Blender suites.

## Package integrity and baseline identity

The portable builder verified extension identity, matching manifest/`bl_info` versions, the generic preset, identical root/package licenses, exact public file membership and ZIP round-trip integrity. `--check-release-request` also verified `release.json` and versioned release notes. All Python source compiled successfully. These checks do not execute the animation workflow.

All ten extension file payloads were compared byte-for-byte with the original 1.4.0 installable ZIP; none changed. Repository documentation, normalized ZIP metadata and public-pack contents differ intentionally. Production scenes, character-specific calibration presets, installation profiles and the official plugin's source are excluded.
