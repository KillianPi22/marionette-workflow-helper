# Marionette Workflow Helper 1.4.0

Install `marionette_workflow-1.4.0.zip` using Blender's **Install from Disk** command. The outer delivery pack includes the English guide, generic Mixamo mapping preset and GPL license.

This publishes the existing 1.4.0 addon baseline in its own repository. All ten extension file payloads are unchanged from the original installable ZIP. Repository documentation, portable build scripts and synthetic validation support are new; there is no new addon behavior introduced by this migration.

The existing addon includes isolated capture preparation, Mixamo/Tripo reference calibration, manual setup instructions for the official Marionette plugin, transfer to the original character's Action/NLA, interactive correction preview, whole-body alignment, step-height/pelvis controls and adjustable ground compensation.

The public pack excludes private production scenes and character-specific calibration presets. The unchanged historical guide describes some files from that private delivery; read `READ_FIRST.md` for the public contents. Generate a fresh calibrated preset for your own character. The official Marionette application/plugin are separate requirements and are not bundled.

Historical development recorded 172 successful checks plus installation/upgrade verification on Blender 5.2.1 LTS using private fixtures. These are historical results, not the portable repository's test count. See the repository's validation notes and test instructions for current coverage. GitHub's workflow checks Python syntax and package integrity; it does not run Blender.

The public migration passed 57 fresh checks on Blender 5.2.1 LTS on 2026-11-20: 47 synthetic smoke checks and 10 native-install checks, using isolated profiles and the freshly built ZIP. These checks do not cover the official plugin's live connection or all historical scene migrations.

Ground compensation is manually tuned and does not provide foot locking, collision handling or optical lens undistortion. The supported rigs remain Mixamo-named FK humanoids; this is not a universal retargeter.

Archives are built with normalized metadata and exclude private extras, so their hashes differ from the original delivery. Verify the current downloads with `SHA256SUMS.txt`.
