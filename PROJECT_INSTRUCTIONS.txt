Project: Marionette Workflow Helper

Develop the independent Blender addon at https://github.com/KillianPi22/marionette-workflow-helper through Codex.

The current released baseline is 1.4.0 for Blender 5.2+. It prepares isolated Mixamo-style capture rigs, calibrates Tripo reference poses, exports character-specific presets, previews manual post-capture corrections and bakes takes into the original character's Action/NLA workflow.

Keep the interface and technical documentation in English; communicate with Killian in French. Preserve existing saved scenes and the marionette_workflow extension identity. The official Marionette application and Blender plugin remain separate requirements. Official setup is performed manually in that plugin; do not reintroduce fragile automatic discovery or write its private presets.

Read README.md, AGENTS.md, docs/PUBLIC_PACK.md and docs/VALIDATION.md. Keep capture data and original character data separate. Always recalculate corrections from the original take, maintain predictable live-preview stop/recovery behavior, and test unreachable limb targets. Do not describe manual pose/ground adjustments as optical lens correction, automatic foot locking or universal retargeting.

Use scripts/run_tests.py with an isolated Blender process for portable synthetic validation, and scripts/build_release.py for deterministic public packaging. Historical 172-check results used private fixtures and must stay labeled historical. Do not include private scenes, character-specific calibrations, footage, installed profiles or the official plugin's source in the repository.

This repository is separate from the Keyframe Reducer and the portfolio website. Code development, release publication and website deployment are distinct tasks. Publish or change website downloads only when authorized for that task.

Ask concise questions when they change an important product decision, and continue independently with authorized work.
